# Codex Meter

Windows에서 Codex 주간 사용량을 확인하는 로컬 연동 트레이 앱입니다.

계정 퍼센트와 계정 토큰 합계는 설치된 Codex 실행 파일의 로컬 app-server 상태 프로토콜에서 읽습니다. 데스크톱 앱에 포함된 실행 파일과 npm/Bun CLI 설치를 지원합니다. 앱이 웹 페이지나 HTTP API를 직접 호출하거나 인증 파일을 읽지는 않습니다. 로컬 상태를 사용할 수 없을 때만 `%USERPROFILE%\.codex\sessions`와 `archived_sessions`의 최신 JSONL 값을 대체값으로 사용합니다. `CODEX_HOME`을 지정했다면 해당 폴더에서 로그를 읽습니다.

## 표시값

- **계정 주간 사용률**: Codex의 `account/rateLimits/read` 로컬 상태값입니다. Codex 상태 화면과 같은 `codex` 주간 버킷을 선택합니다.
- **계정 잔여율**: `100 - 계정 주간 사용률`입니다. 화면의 `계정 잔여` 카드와 트레이 아이콘 퍼센트가 이 값입니다.
- **계정 금일 사용률**: 계정의 주간 총용량 중 오늘 증가한 사용률입니다. 주간 제한 창이 오늘 시작됐으면 0%부터 정확히 계산하고, 그 외에는 자정 직전 12시간 안의 로컬 관측값을 기준으로 `약` 값을 표시합니다. 기준값이 없으면 숫자를 만들지 않고 `측정 중`으로 표시합니다.
- **이 PC 처리량**: 현재 주간 제한 창 안에서 이 컴퓨터의 세션 파일에 기록된 실제 토큰과 요청 수입니다. 계정 잔여율과 단위·범위가 다른 별도 지표이며, 오늘 값은 로컬 자정과 주간 창 시작 중 더 늦은 시점부터 집계합니다.
- **추정 주간 절대 한도**: 현재 주간 계정 토큰 합계를 계정 주간 사용률로 나눠 `계정 토큰 ÷ (사용률/100)`으로 역산합니다. Codex가 절대 한도를 직접 제공하지 않으므로 `≈` 추정으로 표시합니다. 주간 창이 막 시작해 현재 날짜 버킷이 아직 없으면 최근 7일 계정 버킷으로 임시 추정하고, 계산 근거가 없으면 `—`와 이유를 표시합니다.
- **계정 사용량 중 이 PC 비중**: 이 PC의 로컬 토큰을 계정 토큰 분모로 나눈 값입니다. 요금제 전체 대비 사용률과 다른 지표이며, 현재 주간 계정 버킷이 없을 때는 최근 7일 계정 버킷을 사용한 `≈` 추정으로 이번 주·오늘 값을 표시합니다. 현재 날짜 버킷이 수신되면 오늘 분모를 정확한 값으로 갱신합니다.
- **이 PC 요금제 추정 사용률**: 이 PC의 실제 로컬 토큰을 추정 주간 절대 한도로 나눈 값입니다. 오늘과 이번 주를 별도로 표시하고, 계정 토큰과 rate-limit 퍼센트가 같은 창에서 확인될 때만 계산합니다.
- **대체 동작**: Codex 로컬 상태를 읽지 못하면 마지막 JSONL 사용률을 표시하고 화면 하단과 트레이 툴팁에 `세션 기록 대체값`이라고 명시합니다.
- **경고선**: 이 PC의 요금제 추정 사용률이 사용자가 정한 값에 도달하면 오버레이와 트레이 아이콘이 빨간색으로 바뀝니다. 계정 전체 사용률은 경고 판정에 사용하지 않고 별도로 표시합니다.
- **트레이 표시**: 아이콘 안의 숫자는 계정의 남은 주간 퍼센트이고, 아이콘 색상은 이 PC 요금제 경고선 상태입니다. 마우스를 올리거나 메뉴를 열면 계정 사용/잔여율, 계정 토큰·추정 주간 절대 한도, 계정 사용량 중 이 PC 비중, 이 PC의 요금제 추정 사용률과 주간 토큰·요청 수를 함께 확인할 수 있습니다.
- **오버레이 이동**: 오버레이의 빈 곳을 끌어 이동할 수 있으며 마지막 위치를 저장합니다.
- **오버레이 표시 모드**: `계정 + 이 PC`에서는 계정 잔여율과 이 PC의 이번 주 요금제 추정 사용률을, `이 PC만`에서는 이 PC의 오늘·이번 주 요금제 추정 사용률을 표시하고 하단에 계정 사용량 중 이 PC 비중을 함께 표시합니다. `최소화 · 숫자 2개`는 계정 주간 잔여율과 이 PC의 주간 추정 사용률만 작은 숫자로 남깁니다. 토큰 수·추정 한도·상세 비중은 대시보드와 트레이에서 확인합니다.
- **오버레이 불투명도**: 대시보드에서 35–100%로 조절할 수 있으며 변경값과 위치를 함께 저장합니다.

Windows가 새 트레이 아이콘을 숨김 영역에 넣은 경우, 숨겨진 아이콘 메뉴에서 `Codex Meter`를 작업표시줄로 한 번 고정하면 숫자가 항상 보입니다. 아이콘 표시 위치는 Windows 사용자 설정이므로 앱이 강제로 바꾸지 않습니다.

Codex rate-limit 상태는 요금제의 절대 토큰 총량이나 기기별 요금제 할당량을 제공하지 않습니다. 앱의 주간 절대 한도와 이 PC 요금제 사용률은 `account/usage/read`의 현재 주간 계정 토큰 합계와 `rateLimits/read`의 사용률을 조합한 추정값이며, Codex가 직접 보고한 공식 한도값이 아닙니다.

## 실행

```powershell
npm install
npm test
npm start
```

설치형 폴더 빌드:

```powershell
npm run pack
```

결과는 `installed\win-unpacked`에 생성됩니다. 다른 PC로 옮길 때는 `.exe`만 복사하지 말고 이 폴더 전체를 복사하세요. 패키징된 앱 실행에는 Node.js가 필요 없지만, 대상 PC에도 Codex가 설치되어 있어야 합니다.

로그인 자동 시작 등록 또는 복구(소스 저장소 폴더에서 실행):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install-startup.ps1
Start-ScheduledTask -TaskName CodexMeter
```

다른 PC에서도 이 등록 스크립트를 쓰려면 `scripts\install-startup.ps1`과 `installed\win-unpacked`를 **동일한 상위 폴더 아래 같은 구조**로 복사하세요. `win-unpacked`만 복사하면 수동 실행은 가능하지만 이 등록 스크립트는 포함되지 않습니다. 또는 대상 PC에서 저장소를 받아 빌드한 뒤 위 명령을 실행하세요.

현재 사용자가 로그인한 뒤 20초 후 `CodexMeter` 예약 작업이 실행 파일을 직접 시작합니다. 화면을 표시할 수 있는 사용자 세션에서 실행하며, 오류 코드로 종료되면 1분 간격으로 최대 3회 재시도합니다. 배터리 사용이나 기본 실행 시간 제한 때문에 종료되지 않도록 설정합니다. 기존의 동일 실행 파일용 `HKCU Run` 항목은 `installed\startup-before.json`에 백업한 뒤 제거합니다. 폴더를 옮겼다면 등록 스크립트를 다시 실행하세요.

실행 상태와 마지막 실행 시각은 `Get-ScheduledTask -TaskName CodexMeter` 및 `Get-ScheduledTaskInfo -TaskName CodexMeter`로 확인합니다. 예약 작업에서 정상 실행 중인 앱은 결과 코드 `267009` (`0x41301`, 실행 중)로 표시될 수 있습니다. 중지는 `Stop-ScheduledTask -TaskName CodexMeter`, 다음 로그인 자동 시작 해제는 `Disable-ScheduledTask -TaskName CodexMeter`입니다.

설정 근거: Microsoft의 [사용자 세션 지정](https://learn.microsoft.com/en-us/powershell/module/scheduledtasks/new-scheduledtaskprincipal) 및 [재시도·실행 제한 설정](https://learn.microsoft.com/en-us/powershell/module/scheduledtasks/new-scheduledtasksettingsset).

## 다른 PC에서 사용량을 읽지 못할 때

대시보드 상단에 실행 파일 누락, 로그인 문제, 미지원 조회 기능, 응답 시간 초과 등을 표시합니다. 로컬 토큰 수는 계속 집계하고, 계산 근거가 없는 비율은 `계산 불가` 또는 `—`로 표시합니다. 지원되지 않는 계정 토큰 조회 때문에 정상적인 계정 잔여율 조회까지 취소하지 않습니다.

1. Codex 데스크톱 앱을 한 번 실행하거나 Codex CLI를 설치하고, **같은 Windows 사용자**의 Codex에서 ChatGPT 계정으로 로그인하세요. API 키 전용 로그인은 계정 사용량 조회를 지원하지 않습니다.
2. 미지원 기능 메시지가 보이면 Codex를 업데이트한 뒤 Meter에서 새로고침하세요. 실패한 연결은 다음 조회에서 다시 만들며 실행 파일도 다시 검색합니다. 느린 PC의 초기 연결은 최대 30초, 사용량 응답은 최대 20초 기다립니다. 이후 20초 주기로 재시도합니다.
3. 특수한 설치 경로라면 `CODEX_METER_CODEX_PATH`에 `codex.exe`의 **절대 경로**를 지정하세요. 이 값은 자동 검색보다 우선하며, 잘못된 경로면 다른 설치본을 임의로 실행하지 않습니다. 데이터 폴더를 옮겼다면 `CODEX_HOME`도 지정하세요. 환경 변수 변경 후에는 Meter를 다시 실행해야 합니다.
4. 개발 환경에서 `npm run inspect`를 실행하면 출력의 `connection`에 선택된 실행 파일, 데이터 폴더, 조회별 오류가 나옵니다. 대시보드 하단 파일 수에 마우스를 올려도 경로를 확인할 수 있습니다. 진단 출력을 공유할 때는 사용자 이름·경로·사용량을 확인하세요.

연결은 OpenAI의 [App Server 초기화·계정 조회 프로토콜](https://learn.chatgpt.com/docs/app-server)에 따라 `initialize` → `initialized` 순서로 수행합니다. 계정에서 일별 토큰 내역을 제공하지 않는 경우, Meter만으로 정확한 기기별 요금제 비율을 복원할 수는 없습니다.

## 개인정보

프롬프트와 응답 본문은 저장하지 않습니다. 스캐너는 `token_count`, `rate_limits`, 타임스탬프만 메모리에 집계하며 계정 인증 파일에는 접근하지 않습니다.
