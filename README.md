# Codex Meter

Windows에서 Codex 주간 사용량을 확인하는 로컬 전용 트레이 앱입니다.

앱은 `%USERPROFILE%\.codex\sessions`와 `archived_sessions`의 JSONL만 읽습니다. 네트워크 요청, 인증 파일 접근, API 호출은 하지 않습니다.

## 표시값

- **계정 주간 사용률**: 가장 최근 로컬 세션의 `rate_limits`가 보고한 계정 전체 값입니다.
- **계정 잔여율**: `100 - 계정 주간 사용률`입니다.
- **이 PC 처리량**: 현재 주간 제한 창 안에서 이 컴퓨터의 세션 파일에 기록된 실제 토큰과 요청 수입니다.
- **경고선**: 계정 전체 사용률이 사용자가 정한 값에 도달하면 오버레이와 트레이 아이콘이 빨간색으로 바뀝니다.
- **트레이 표시**: 아이콘 안의 숫자는 계정의 남은 주간 퍼센트입니다. 마우스를 올리거나 메뉴를 열면 계정 사용/잔여율과 이 PC의 주간 토큰·요청 수를 함께 확인할 수 있습니다.
- **오버레이 이동**: 오버레이의 빈 곳을 끌어 이동할 수 있으며 마지막 위치를 저장합니다.
- **오버레이 불투명도**: 대시보드에서 35–100%로 조절할 수 있으며 변경값과 위치를 함께 저장합니다.

Windows가 새 트레이 아이콘을 숨김 영역에 넣은 경우, 숨겨진 아이콘 메뉴에서 `Codex Meter`를 작업표시줄로 한 번 고정하면 숫자가 항상 보입니다. 아이콘 표시 위치는 Windows 사용자 설정이므로 앱이 강제로 바꾸지 않습니다.

Codex 로컬 로그는 요금제의 절대 토큰 총량이나 다른 컴퓨터별 사용량을 제공하지 않습니다. 따라서 이 PC의 토큰을 계정 용량의 퍼센트로 거짓 환산하지 않습니다.

## 실행

```powershell
npm install
npm test
npm start
```

설치형 폴더 빌드:

```powershell
npm run pack
```

결과는 `installed\win-unpacked`에 생성됩니다.

## 개인정보

프롬프트와 응답 본문은 저장하지 않습니다. 스캐너는 `token_count`, `rate_limits`, 타임스탬프만 메모리에 집계합니다.
